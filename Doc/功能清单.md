**拆分规则**：前后端拆为独立功能点，多平台拆为独立功能点。每个功能点保持 3 维状态（实现/测试/注释）。

## 拆分决策表

| 需求项 | 原因 | 拆分结果 |
|--------|:----:|---------|

> 本项目为**纯 API 类库**（无前端 UI、无 Cube 管理后台），所有功能点不拆分前后端；跨平台实现统一（仅以条件编译处理 GB2312 编码注册），不按平台拆分。故**无拆分项**。
