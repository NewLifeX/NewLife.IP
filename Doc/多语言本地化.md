# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 11 种语言｜英文为源文与兜底

## 1. 语言分层

本库按 NuGet 下载量分层维护运行时词表：下载量较高的核心组件对齐 NewLife.Core 的 31 种语言，其余组件维护 11 种语言（与 README 读者一致）。缺失译文在运行时自动回退英文，新增语言不需要改代码。

词表文件（10 个，另有英文源文兜底）：

- zh-Hans
- zh-Hant
- es
- de
- ja
- fr
- pt
- ru
- ko
- ar

## 2. 词表文件

- `NewLife.IP/Locales`

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。

## 3. 新增一条消息

1. 代码中写英文源文：`throw new XException("Session {0} is closed.", sessionId);`，日志直接写英文模板（`Logger.Format` 自动翻译）。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

### 3.1 带前缀日志

日志前缀（如 `[IP]`）随实例变化，必须**在翻译之后**拼接。本库统一使用 NewLife.Core 的 `InfoPrefixed` / `ErrorPrefixed`：先按日志语言翻译原始模板，再拼前缀，避免整串查表永远回退英文。

| 组件 | 日志对象 | 默认前缀 |
|------|----------|----------|
| `Ip` | `Ip.Log`（默认 `XTrace.Log`，初始化时传给 `IpDatabase`） | `[IP] ` |
| `IpDatabase` | `IpDatabase.Log`（默认 `XTrace.Log`） | `[IpDatabase] ` |
| `IpCsv` | `IpCsv.Convert(csvFile, dbFile, log)`（为空时使用 `XTrace.Log`） | `[IpCsv] ` |
| `OnlineIp` | `OnlineIp.Log`（默认 `XTrace.Log`） | `[OnlineIp] ` |

```csharp
var ip = new Ip { Log = myLogger, LogPrefix = "[IP] " };
```

日志语言独立于界面语言：`Localization.Culture` 控制异常与界面文案，`Localization.LogCulture` 控制日志（为空时跟随 `Culture`）。需要固定宿主语言时设置 `LogCulture`，避免请求语言切换导致日志语言抖动。`InvariantGlobalization` 模式下具名区域性不可用，词表不注册，日志按英文源文输出。

## 4. 校验

```powershell
pwsh -File check-locales.ps1 -LocaleDir NewLife.IP/Locales -Baseline zh-Hans.yml -SourceDir NewLife.IP
```

CI 的 localization job 会执行同一脚本。
