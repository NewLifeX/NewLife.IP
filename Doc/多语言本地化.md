# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 31 种语言｜英文为源文与兜底

## 1. 语言覆盖

本库运行时词表对齐 NewLife.Core 的 31 种语言，英文为源文与兜底。缺失译文在运行时自动回退英文，新增语言不需要改代码。

词表文件（35 个，另有英文源文兜底）：

- ar、bn、cs、da、de、el、es、fa、fi、fr、he、hi、hu、id、it、ja、ko、ms、nb、nl、pl、pt、ro、ru、sv、th、tr、uk、vi
- zh-Hans、zh-Hant
- iw、in、no、mo（旧式区域名别名，分别复用 he、id、nb、ro 译文）

> 旧式区域名：`iw`（希伯来语）、`in`（印尼语）、`no`（挪威语）、`mo`（摩尔多瓦语）在部分旧应用或配置中仍会出现，已提供同名别名词表。`zh-CHT` 由 NewLife.Core 的 `GetCultureKey` 统一映射到 `zh-Hans`，如需繁体请使用 `zh-TW` / `zh-HK` / `zh-MO` / `zh-Hant`。

## 2. 词表文件

- `NewLife.IP/Locales`

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。

## 3. 新增一条消息

1. 代码中写英文源文：`throw new XException("Session {0} is closed.", sessionId);`，日志直接写英文模板（`Logger.Format` 自动翻译）。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

### 3.1 带前缀日志

日志前缀（如 `[IP]`）随实例变化，必须**在翻译之后**拼接。本库统一使用 NewLife.Core 的 `InfoPrefixed` / `ErrorPrefixed`：先按日志语言翻译原始模板，再拼前缀，避免整串查表永远回退英文。

| 组件 | 日志对象 | 默认前缀 |
|------|----------|----------|
| `Ip` | `Ip.Log`（默认 `XTrace.Log`，初始化时传给 `IpDatabase`） | `[IP] ` |
| `IpDatabase` | `IpDatabase.Log`（默认 `XTrace.Log`） | `[IpDatabase] ` |
| `IpCsv` | `IpCsv.Convert(csvFile, dbFile, log)`（为空时使用 `XTrace.Log`） | `[IpCsv] ` |
| `OnlineIp` | `OnlineIp.Log`（默认 `XTrace.Log`） | `[OnlineIp] ` |

```csharp
var ip = new Ip { Log = myLogger, LogPrefix = "[IP] " };
```

日志语言独立于界面语言：`Localization.Culture` 控制异常与界面文案，`Localization.LogCulture` 控制日志（为空时跟随 `Culture`）。需要固定宿主语言时设置 `LogCulture`，避免请求语言切换导致日志语言抖动。`InvariantGlobalization` 模式下具名区域性不可用，词表不注册，日志按英文源文输出。

### 3.2 数据库文本编码

IP 数据库记录区统一按 **GB18030** 编解码（GB2312/GBK 的超集）：

- 既有 GB2312/GBK 数据可直接读取；
- `IpCsv` 转换 DB-IP CSV 时，`São Paulo`、`القاهرة`、`서울` 等多语言地名不再被写成 `?`；
- 超过 64 字节的长地名按需扩容缓冲，不截断、不错位；
- .NET Core / Android / iOS 首次使用 `IpDatabase` 或 `IpCsv` 时自动注册代码页提供程序，无需调用方手工注册；
- `netstandard2.0` / `netstandard2.1` 资产运行在 .NET Core 宿主时，通过反射注册代码页提供程序（不引入额外 NuGet 依赖）；.NET Framework 宿主自带代码页编码。

## 4. 校验

```powershell
pwsh -File tools/check-locales.ps1 -LocaleDir NewLife.IP/Locales -Baseline zh-Hans.yml -SourceDir NewLife.IP
```

CI 的 localization job 会执行同一脚本。
