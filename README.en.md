NewLife.IP offers high-performance IP lookups for IPv4/IPv6, global addresses and Chinese administrative regions, with bundled data files ready to use.

## Installation

```bash
dotnet add package NewLife.IP
```

## Quick start

```csharp
var ip = new IpAddress("114.114.114.114");
var area = ip.GetArea();
```

## Key features

- High throughput and low latency, proven at production scale
- Built-in capabilities and data; runs without external services
- Cross-platform: Windows, Linux, macOS and ARM64/LoongArch64
