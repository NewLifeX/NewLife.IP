NewLife.IP は IPv4/IPv6、国内外アドレス、中国の行政区画に対応した高速 IP 検索を提供し、データファイルを同梱しています。

## インストール

```bash
dotnet add package NewLife.IP
```

## クイックスタート

```csharp
var ip = new IpAddress("114.114.114.114");
var area = ip.GetArea();
```

## 主な機能

- 高スループット・低遅延で、大規模本番環境で実証済み
- 機能とデータを内蔵し、外部サービスなしで動作
- クロスプラットフォーム：Windows / Linux / macOS / ARM64 / LoongArch64
